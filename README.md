# 8-Bit ALU Design Using Verilog

## Project Description
This project implements an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL.

## Operations
- Addition
- Subtraction
- Bitwise AND
- Bitwise OR
- Bitwise XOR

## Tools Used
- Verilog HDL
- Icarus Verilog
- GTKWave
- Visual Studio Code

## Project Files
- alu.v - ALU design
- tb_alu.v - Testbench
- README.md - Project documentation

## Simulation
The design is compiled and simulated using Icarus Verilog. Waveforms can be viewed using GTKWave.
